# LSM6DS3TR-C Maintained Implementation Reference

The maintained, source-audited chip reference is
[docs/chip-reference/00_reference_index.md](docs/chip-reference/00_reference_index.md).

It contains the current official ST source manifest, register and protocol
facts, ODR/power constraints, conversions, filters and settling rules, FIFO and
embedded-engine behavior, exact AN5130 self-test procedures, known ST source
ambiguities, and the library support matrix.

The previous monolithic extraction is preserved as an explicitly unsafe audit
archive at
[docs/archive/LSM6DS3TR_imu_legacy_extraction.md](docs/archive/LSM6DS3TR_imu_legacy_extraction.md).
It must not be used as an implementation source.
